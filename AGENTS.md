# Cutetix – AI Development Instructions

## General
- Make minimal, focused changes.
- Reuse existing components, services and patterns.
- Do not refactor unrelated code.
- Do not modify backend code when working on the frontend.
- Do not install dependencies unless explicitly requested.
- Do not create branches, commits or pull requests unless requested.

## Token efficiency
- Inspect only files relevant to the task.
- Avoid scanning the entire repository unless necessary.
- Avoid unnecessary research and repeated tool calls.
- Do not launch subagents unless explicitly requested.
- Ask before expanding the scope of work.

## Validation
- Do not create, modify or run tests unless explicitly requested.
- Do not run builds or linters automatically.
- Briefly explain what was changed and what remains unverified.

## Frontend
- Follow existing Angular patterns.
- Prefer Angular Signal Forms for new forms.
- Respect global and event-local permissions.
- Reuse existing toastr services.
- Keep UI responsive.

## Workflow
- One task at a time.
- Keep diffs small.
- Explain blockers instead of implementing workarounds.
